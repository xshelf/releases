# XShelf releases

Downloads and update feeds for [XShelf](https://app.xshelf.net), a private video library.

- **Get started:** [app.xshelf.net](https://app.xshelf.net) has the downloads, a beta key and the setup guide.
- **Desktop apps** (Mac, Windows, Linux) are attached to each [release](https://github.com/xshelf/releases/releases). Installed apps update themselves from here.
- **The server** is the Docker image [`ghcr.io/xshelf/xshelf`](https://github.com/orgs/xshelf/packages/container/package/xshelf).

This repository holds release files only.
